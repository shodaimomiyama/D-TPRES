# サブタスクメッセージテンプレート

このテンプレートは、オーケストレータがサブタスクを作成する際に使用するメッセージの構造を定義します。

## 基本構造

```
# [サブタスク名]

## 親タスクの概要
[親タスクの簡潔な説明]

## このサブタスクの目的
[このサブタスクが達成すべき具体的な目標]

## 詳細要件
- [要件1]
- [要件2]
- ...

## 実装方針
1. [ステップ1]
2. [ステップ2]
3. ...

## 重要な注意事項
- テストを実行する前に必ず `make lint` を実行し、リントエラーがある場合は修正してください。
- 実装が困難な場合（無限ループなど）は、問題を明確に説明し、実装を中止してください。
```

## 使用例

```
# オーダーエンティティにステータス更新機能を追加する

## 親タスクの概要
オーダー監視エンジンの機能強化として、オーダーのステータスを更新する機能を実装します。

## このサブタスクの目的
オーダーエンティティにステータス更新メソッドを追加し、ステータス変更のバリデーションを実装します。

## 詳細要件
- オーダーエンティティに `update_status` メソッドを追加する
- 無効なステータス遷移を防ぐバリデーションロジックを実装する
- ステータス変更時にタイムスタンプを更新する

## 実装方針
1. `src/domain/entity/order.rs` ファイルを開く
2. Order 構造体に `update_status` メソッドを追加する
3. ステータス遷移のバリデーションロジックを実装する
4. 単体テストを追加する

## 重要な注意事項
- テストを実行する前に必ず `make lint` を実行し、リントエラーがある場合は修正してください。
- 実装が困難な場合（無限ループなど）は、問題を明確に説明し、実装を中止してください。
